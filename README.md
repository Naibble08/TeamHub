# TeamHub

Автоматизированная система постановки задач, документооборота, коммуникаций и
автоматических напоминаний с использованием LLM — для команд до 30 человек.

Реализовано по техническому заданию «TeamHub» (v1.0): подсистемы аутентификации,
задач, документооборота, чата и автоматических напоминаний (дни рождения, сроки задач),
включая обязательные функции на основе LLM (генерация поздравлений, напоминаний и
произвольных сообщений через ИИ-ассистента в чате) с адаптером под разных поставщиков
модели и шаблонным откатом при недоступности ИИ.

## Стек

- Сервер: Node.js (LTS) + Express + Socket.IO + better-sqlite3 (SQLite, режим WAL)
- Клиент: статические HTML/CSS/JavaScript без сборки
- Пароли: bcrypt-хэши; авторизация: JWT (срок жизни ≤ 30 суток)

## Быстрый старт

**Windows, без командной строки:** запустите `installers\server\install-server.bat`
на компьютере-сервере, затем `installers\client\install-client.bat` на каждом
рабочем месте — оба мастера всё сделают сами. Подробности — [installers/README.md](installers/README.md).

**Вручную (любая ОС):**

```bash
npm install
npm start
```

При первом запуске сервер:

1. создаёт `config/config.json` из `config/config.example.json` со случайным `jwtSecret`;
2. создаёт файл базы данных `data/teamhub.db`;
3. создаёт первую учётную запись администратора (логин `admin`) со случайным паролем —
   он один раз выводится в консоль. Смените его сразу после первого входа.

Приложение будет доступно на `http://localhost:3000` (порт задаётся в `config/config.json`).

Подробная инструкция администратора — см. [docs/ADMIN_GUIDE.md](docs/ADMIN_GUIDE.md).
Описание базы данных и API — см. [docs/DATABASE.md](docs/DATABASE.md) и [docs/API.md](docs/API.md).
Журнал версий — см. [CHANGELOG.md](CHANGELOG.md).

## Структура проекта

```
installers/            установщики для Windows: server/ (сервер), client/ (рабочее место)
config/            конфигурация сервера (config.json не входит в поставку кода)
src/
  db/               схема и инициализация SQLite
  middleware/        авторизация (JWT)
  routes/            REST API
  services/          бизнес-логика: задачи, напоминания, LLM-адаптер, настройки
    llm/
      providers/      реализации поставщиков (gemini, ollama)
  sockets/            чат в реальном времени (Socket.IO)
  utils/              пароли, токены, шаблоны сообщений
  app.js, server.js   сборка приложения и точка входа
public/               клиентская часть (HTML/CSS/JS)
docs/                 документация (админ-инструкция, API, БД)
uploads/               файлы документооборота (не в git)
data/                  файл базы данных (не в git)
```

## Функции ИИ

По умолчанию поставлен как `template` (без обращения к внешним сервисам) — все LLM-функции
работают на заранее заданных шаблонах. Чтобы подключить облачного (Google Gemini) или
локального (Ollama) поставщика, отредактируйте `config/config.json` — подробности в
[docs/ADMIN_GUIDE.md](docs/ADMIN_GUIDE.md#функции-ии-llm).
