# Программный интерфейс (API)

Все запросы (кроме `/api/auth/login`) требуют заголовок `Authorization: Bearer <токен>`,
полученный при входе. Формат ответа — JSON. Realtime-события чата — через Socket.IO
(`/socket.io`), авторизация — `auth: { token }` в handshake.

## Аутентификация — `/api/auth`

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| POST | `/login` | все | `{ login, password }` → `{ token, user }` |
| GET | `/me` | авторизован | текущий пользователь |
| POST | `/change-password` | авторизован | `{ oldPassword, newPassword }` |

## Сотрудники — `/api/users`

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/` | авторизован | список; администратору — полные карточки и неактивные |
| POST | `/` | admin | создать сотрудника |
| PUT | `/:id` | admin | изменить карточку (пароль — опционально) |
| POST | `/:id/deactivate` | admin | деактивировать |
| POST | `/:id/activate` | admin | активировать |

## Задачи — `/api/tasks`

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/?scope=my\|all` | авторизован | `all` — только для admin |
| GET | `/:id` | участник задачи / admin | |
| POST | `/` | admin | `{ title, description, dueDate, assigneeIds[] }` |
| PUT | `/:id` | admin | изменение полей и состава исполнителей |
| POST | `/:id/status` | постановщик / исполнитель / admin | `{ status }` — new/in_progress/done |

Перевод в статус `overdue` выполняется только автоматически планировщиком.

## Документы — `/api/documents`

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/` | авторизован | документы, доступные пользователю |
| POST | `/` | авторизован | multipart: `file`, `recipientId` (опционально) |
| GET | `/:id/download` | получатель / автор / admin | скачивание файла |

## Сообщения — `/api/messages`

| Метод | Путь | Описание |
|---|---|---|
| GET | `/general` | история общего канала |
| GET | `/system` | личные системные напоминания текущего пользователя |
| GET | `/with/:userId` | история переписки с конкретным пользователем |

Отправка сообщений и генерация через ИИ-ассистента — только через Socket.IO (см. ниже);
REST используется исключительно для начальной загрузки истории.

## Настройки — `/api/settings` (только admin)

| Метод | Путь | Описание |
|---|---|---|
| GET | `/` | текущие настройки напоминаний и тона сообщений |
| PUT | `/` | изменить настройки |
| POST | `/run-checks` | ручной запуск проверки дней рождения и дедлайнов (п. 8.1) |
| GET | `/llm-logs` | последние 200 записей журнала обращений к LLM |

## Socket.IO события

| Событие | Направление | Payload | Описание |
|---|---|---|---|
| `chat:send` | клиент → сервер | `{ toUserId\|null, content, isLlmGenerated?, llmProvider? }`, ack | отправка сообщения (личное или в общий канал) |
| `chat:message` | сервер → клиент | сообщение | доставка нового сообщения (личного, общего или системного) |
| `chat:ai-generate` | клиент → сервер | `{ instruction }`, ack `{ text, provider, isFallback }` | функция «ИИ-ассистент» (п. 5.6.3) |
