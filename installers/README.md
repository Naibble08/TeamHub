# Установщики TeamHub

Два независимых мастера установки для Windows — под сервер и под рабочее место
сотрудника. Оба запускаются двойным щелчком, без предварительной настройки.

| | Кто запускает | Что делает |
|---|---|---|
| [`server/install-server.bat`](server/) | тот, кто разворачивает систему | ставит Node.js при необходимости, устанавливает зависимости, включает автозапуск сервера при загрузке компьютера, открывает порт в брандмауэре |
| [`client/install-client.bat`](client/) | каждый сотрудник на своём компьютере | спрашивает адрес сервера и кладёт значок TeamHub на рабочий стол |

Порядок действий:

1. Скопируйте всю папку TeamHub на компьютер, который будет сервером, и запустите
   `installers\server\install-server.bat` — один раз.
2. Заберите у него пароль администратора и адрес сервера (оба выводятся в конце
   установки).
3. На каждом рабочем месте запустите `installers\client\install-client.bat` и
   укажите этот адрес.

Подробности и решение проблем — в README внутри каждой папки:
[`server/README.md`](server/README.md), [`client/README.md`](client/README.md).

Понятная инструкция по работе с самой системой (не про установку) — в корне
