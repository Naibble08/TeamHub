# Установщик сервера TeamHub

Для компьютера, который будет постоянно работать сервером TeamHub в локальной
сети организации (Windows 10/11 или Windows Server).

## Что делает `install-server.bat`

1. Проверяет и, если нужно, ставит Node.js (через `winget`, а если его нет —
   скачивает официальный установщик с nodejs.org).
2. Устанавливает зависимости проекта (`npm install`).
3. Настраивает автозапуск сервера через Планировщик заданий Windows — сервер
   будет включаться сам при каждой загрузке компьютера, ещё до входа в систему,
   и работать в фоне без открытого окна.
4. Открывает порт 3000 в брандмауэре Windows для локальной сети.
5. Сразу запускает сервер и показывает журнал первого запуска — там же логин
   и одноразовый пароль администратора.

## Как запустить

Дважды щёлкните `install-server.bat`. Скрипт сам запросит права администратора
(появится стандартный запрос Windows «Разрешить этому приложению вносить
изменения на вашем устройстве?») — это ожидаемо и необходимо для установки
Node.js, настройки автозапуска и брандмауэра.

По окончании запишите:
- пароль администратора (показан один раз, в журнале запуска);
- адрес сервера в локальной сети (показан в самом конце, вида
  `http://192.168.1.10:3000`) — он понадобится для установки на рабочих местах.

## После установки

- Проверить, что сервер работает: откройте показанный адрес в браузере на
  любом компьютере в той же сети.
- Посмотреть журнал сервера: файл `logs\server.log` в папке TeamHub.
- Остановить сервер вручную: `Панель управления → Планировщик заданий →
  TeamHub Server → Завершить`, либо команда PowerShell
  `Stop-ScheduledTask -TaskName "TeamHub Server"`.
- Запустить заново после остановки: `Start-ScheduledTask -TaskName "TeamHub Server"`.
- Изменить настройки ИИ, тайм-ауты, размер загружаемых файлов — файл
  `config\config.json` в папке TeamHub (создаётся автоматически при первом
  запуске). После изменения перезапустите задачу автозапуска.

## Удаление

Запустите `uninstall-server.bat` — уберёт автозапуск и правило брандмауэра.
Данные (`data\`, `uploads\`) и сам код TeamHub при этом не удаляются.

## Если что-то пошло не так

- **«Windows защитила ваш компьютер» при запуске .bat** — это стандартное
  предупреждение SmartScreen для новых файлов из интернета. Нажмите
  «Подробнее» → «Выполнить в любом случае».
- **Node.js не установился автоматически** — установите вручную с
  [nodejs.org](https://nodejs.org) (версия LTS) и запустите `install-server.bat`
  ещё раз, установка не сломается от повторного запуска.
- **Сервер не виден с других компьютеров сети** — проверьте, что компьютеры в
  одной сети, и что стороннее антивирусное ПО с собственным брандмауэром тоже
  разрешает порт 3000 (правило Windows-брандмауэра установщик добавляет сам).
- **Нужен полный протокол для диагностики** — файл `logs\server.log` в папке
  TeamHub копит все сообщения сервера, включая ошибки запуска.
