# Установщик рабочего места TeamHub

Для компьютера сотрудника. TeamHub — веб-страница, отдельная программа не
устанавливается (см. п. 4.1 технического задания) — этот мастер лишь создаёт
удобный значок.

## Что делает `install-client.bat`

1. Спрашивает адрес сервера TeamHub в локальной сети (его выдаёт администратор
   после установки серверной части).
2. Создаёт значок «TeamHub» на рабочем столе и в меню «Пуск».
3. Если на компьютере есть Microsoft Edge или Google Chrome — значок открывает
   TeamHub в отдельном окне без адресной строки и вкладок, как обычную
   программу. Если ни того, ни другого нет — открывает в браузере по умолчанию.

Прав администратора не требует — значок создаётся только для текущего
пользователя Windows.

## Как запустить

Дважды щёлкните `install-client.bat`, введите адрес сервера (например,
`192.168.1.10`) и нажмите Enter. Готово — значок на рабочем столе.

Логин и пароль для входа выдаёт администратор при заведении карточки
сотрудника.

## Удаление

Запустите `uninstall-client.bat` — удалит значки с рабочего стола и из меню
«Пуск». На саму систему TeamHub (она на сервере) это не влияет.

## Если что-то пошло не так

- **Ярлык открывает пустую страницу или ошибку подключения** — уточните у
  администратора точный адрес сервера, и что сам сервер запущен.
- **Захотели изменить адрес сервера** — запустите `uninstall-client.bat`, затем
  `install-client.bat` заново с новым адресом.
- **Нет Edge и Chrome** — TeamHub откроется в любом браузере по умолчанию,
  просто без вида отдельного окна-приложения; на работу это не влияет.
